# Cowork outreach — target list & plan (critique-seeking)

**Posture:** humble, critique-seeking, "I built a small experiment, please poke holes in it."
NOT a launch announcement, NOT a pitch. Every message leads with the non-IPCC-affiliation
caveat and the offer to be corrected.

**Gate:** all emails are **DRAFTS only**. Nothing sends until Fred reviews and clicks send.
Calendar holds are personal (no external invites) until Fred approves. Social via Zernio is
staged, not posted.

> **Address policy:** I did not invent personal email addresses. For named individuals the
> "reach via" column lists the appropriate public channel; Fred confirms/fills the actual
> address before sending. Drafts created in Gmail use placeholder recipients
> (`DRAFT-FILL-RECIPIENT@example.com`) so nothing can be sent by accident — replace before send.

| 2 | Tier A community emails — wave 1 (A1, A2, A3) | Gmail (drafts) |
| 3–4 | Tier B researcher emails — wave 2 (B1–B4), personalized | Gmail (drafts) |
| 5 | Post to CCAI Slack / LLM-eval Discord (A4) | manual, by Fred |
| 7 | Tier C journalists — only if Tier A/B yielded signal | Gmail (drafts) |
| 10 | Polite follow-ups to non-responders (1 nudge max) | Gmail (drafts) |

Keep the whole thing quiet and conversational. One nudge maximum per contact. If a reply
says "happy to talk," offer a 30-min Calendar slot.
